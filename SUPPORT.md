# Support

The intended public support route for this development checkpoint is GitHub
Issues:

https://github.com/solomon-cook/abominations-attack-america/issues

The repository page is publicly reachable, but issue creation is currently
restricted. Until that restriction is removed or another route is published,
this is a documented candidate route rather than an active support channel.
GitHub Discussions is not enabled for this repository (the public Discussions
URL returns 404), so it is not an available fallback.
When enabled, use a new issue to report a reproducible bug, request
clarification, or provide playtest feedback. Include the browser, viewport,
commit/version, and steps to reproduce. Do not include room codes, session
tokens, private card information, database URLs, logs containing credentials,
or personal data.

This repository is not a rules-complete public release. Questions about the
physical board, unresolved card effects, or source fidelity should be labelled
as source-review questions rather than treated as confirmed game rules.
