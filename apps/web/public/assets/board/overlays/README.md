# Hex overlays

Deterministic transparent SVG artwork generated by scripts/build-hex-overlays.mjs, based on the original board's compact printed symbols. City colours distinguish 1 HP, 1D, 2D and 3D. Branch colours follow the project military palette.

City, Infamy and Mutation symbols use a 200 × 86 viewBox and fit within the upper half. Lairs use hand-authored vector monster emblems (paths and circles only, no embedded raster images). Each emblem is also exported as monster-NAME.svg on a transparent background. Challenge and all six monster-specific lairs use a 200 × 173.205 flat-top hex viewBox and fill the whole tile. Base stars use 64 × 64 and render as a centred horizontal row in the lower half. All overlays have transparent backgrounds; the live board tones down full-hex site symbols so terrain remains visible. Labels and benefits remain data-driven in the renderer.
