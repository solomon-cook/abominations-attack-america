## Resolution status

Rows marked `open-source-gated` or `open-review` are visible blockers. `open-source-gated` means the current audit has identified a rule gap, but authoritative evidence or an implementation boundary is still missing; `open-review` means the data is implemented and validated, while a named acceptance or sign-off remains. `resolved` records a closed data boundary while preserving the evidence trail. No engine fallback may silently substitute a guessed value. Close a blocker only when its required evidence is attached to the corresponding typed data and test fixture.
