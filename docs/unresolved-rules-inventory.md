## Resolution status

All rows above are visible blockers. `open-source-gated` means the current audit has identified the gap, but the authoritative evidence or implementation boundary is still missing; it is not a production-ready status. No engine fallback is allowed to silently substitute a guessed value. A row can be closed only when its required resolution evidence is attached to the corresponding typed data and test fixture.
