# Release notes — development checkpoint

## Current checkpoint

- Shared deterministic engine, HTTP rooms, WebSocket updates, polling fallback, persistence boundaries, spectator projections, and reconnect-safe command receipts are implemented for the development fixture.
- New MVP matches pin and render the 336-cell `AUDITED_BOARD` for rules and legality. The project owner approved its reviewed spaces, features, edges, bases, and city benefits on 8 October 2026 and accepted its same-scale visual review on 11 October 2026 with no issues found. The nine-space board remains an isolated development fixture; independent board review and production-persistence acceptance remain open.
- Settings include larger text, board-label visibility, reduced motion, and disappearance/concession confirmation behavior.
- Voluntary concession, safe terminal return, local rematch, deterministic malformed-command coverage, bounded concurrency coverage, asset checks, and accessibility source checks are included.

## Not a production release

This checkpoint is not a public rules-complete release. Board data is transcribed, validated, signed off by the project owner, and used by new MVP matches; its independent review and production-persistence checks are still pending. The project owner accepted the same-scale visual review on 11 October 2026 with no issues found. Card-interaction rules remain source-gated, while broader human browser and accessibility acceptance, deployed infrastructure, privacy and content/IP approval, and release operations also remain outstanding.

## Support

The documented [GitHub Issues support route](../SUPPORT.md) is publicly
reachable and repository metadata reports Issues enabled. Signed-out visitors
are redirected to sign in; submission by an ordinary signed-in player has not
been verified. It is not yet claimed as an active support channel. GitHub
Discussions is disabled. Please do not include secrets, room tokens, private
game information, or personal data in any report.
