# Rules and content review sign-off

## Owners

| Review area | Owner | Required evidence |
| --- | --- | --- |
| Board data and topology | Project maintainer, with a second human reviewer | Annotated board comparison, source references, validator output |
| Component statistics and inventories | Project maintainer, with a second human reviewer | Catalogue row, source image region, typed data, focused test |
| Rules interpretation and digital adaptations | Project maintainer | Rules-reference anchor, adaptation entry, engine/UI/test mapping |
| Shipped media and wording | Project maintainer plus release reviewer | Provenance manifest, licence/ownership check, final asset review |

No production board, component rule, or release asset is considered signed off merely because the code builds. Sign-off is recorded beside the affected data or release checklist when the required evidence exists.
