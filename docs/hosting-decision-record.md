# Hosting decision record

## Decision

**Selected architecture:** Vercel Functions for the HTTP API and Prisma Postgres for shared durable state. The API uses the existing HTTP polling/reconnect path; WebSockets, the persistent Node listener, `LISTEN/NOTIFY`, and background timers are not used in the Vercel adapter. The owner confirmed this is a non-commercial hobby app, approved Vercel Hobby, and approved a dedicated Prisma Postgres Production database on Free for $0 with no overages.

**Current Production evidence (5 November 2026):** canonical site `https://abominations-attack-america.vercel.app` serves deployment `dpl_HVLoeBb7mdzjRLJqQyi71iRHCWqo` from `main` commit `1fde103eb01d0255da3d2619fac640ee25652ff1` after the pooled credential rotation; `/api/health` and `/api/metrics` return HTTP 200. The server uses the encrypted pooled `DATABASE_URL`; `DIRECT_URL` is server-side for migrations. Two isolated browser sessions created and joined a private room, waited for host start, completed nine setup actions, exchanged a legal move at revision 11, observed the same authoritative revision, and recovered it after refresh. This verifies a synthetic multiplayer path, not a full human match or release readiness.

**Operational boundary:** Prisma Free is $0 with a hard 200,000-operation workspace-shared monthly cap and no automated backups. At 20:42 UTC the five-project workspace meter was 24,402/200,000. Two continuously open tabs polling every 30 seconds are estimated at 172,800 operations per 30 days under a one-operation-per-poll assumption; four continuous players exceed the cap. A one-time manual dump/restore drill passed, but routine ownership and schedule remain open. Production is deployed for friend playtests, but it is not recorded as production-ready until capacity, recurring recovery, complete human-match/spectator, security/rules, rollback, and release-approval gates are complete. See the dated evidence below and [`config/hosting-observation.json`](../config/hosting-observation.json).

The dated observations below preserve the progression of the decision and superseded failures; use the latest Production evidence above and the final dated Production section for current status.

## Options and decision criteria

The eventual provider must support the requirements in [`docs/deployment-requirements.md`](deployment-requirements.md): static web delivery, durable API compute, WebSockets and polling fallback, managed Postgres with Prisma migrations and backup/restore, environment-scoped secrets, and observable health and failure signals. The decision must be based on those capabilities and on a reversible operational path, not on provider branding.

The following must be recorded before the API/database selection:

- separate staging and production URLs, databases, credentials, allowed origins, logs, and alert destinations;
- HTTPS/WSS and proxy upgrade behaviour, request/time-out limits, rate-limit controls, and secret rotation;
- migration ownership, backup retention, restore access, rollback strategy, and incident escalation;
- cost, access ownership, regional/data handling constraints, and an exit path.

## Free and Prisma-compatible hosting decision

**Constraint:** use a fully free setup, or use Prisma Postgres as the database. The previous Render Hobby API-plus-Render-Postgres recommendation and its $13/$19/$26 monthly estimates are withdrawn; do not provision the Blueprint as written. Paid API compute remains an option when paired with Prisma Postgres. A separate Preview project/database is retained for synthetic staging. On 5 November, the owner approved and we provisioned the dedicated Free Production database and configured its encrypted Vercel credentials; see the latest Production verification below.

**No-always-on API candidate:** keep the static Vercel frontend and expose the API as Vercel Functions with Prisma Postgres as the only database. The deployed implementation uses short HTTP handlers and the existing polling fallback; WebSockets remain disabled. This avoids operating an always-on API process, but still requires durable storage and server-side credentials. Vercel Hobby includes up to 1 million function invocations monthly and is limited to personal/non-commercial use; the owner confirmed this is a non-commercial hobby app. Prisma Postgres Free includes 200,000 shared operations monthly and no automated backups. This combination is deployed for the approved personal/hobby Production use, but is not designated production-ready while the documented capacity and recovery gates remain open. The latest earlier Preview build passed two-profile room setup, a server-accepted legal action, shared-state observation, and reload recovery. The 5 November Prisma Console check observed 11,728 workspace operations and 147 operations grouped under the Preview project; a tested backup/restore path remains open. See [Vercel Hobby plan limits](https://vercel.com/docs/plans/hobby) and [Prisma Postgres pricing](https://www.prisma.io/pricing).

This makes the Starter database practical only if measured traffic stays low or presence writes are substantially reduced.
